# Читательский дневник / ReadingJournal

Личная книжная полка с оценками и короткими впечатлениями. Цель проекта — помогать человеку помнить, **почему** ему понравилась книга, и выбирать следующую на основе его интересов.

Проект также готовится как открытая работа для GitHub-портфолио Forvid: с понятными требованиями, проверяемым алгоритмом, тестами и публичной демонстрацией.

> **Состояние:** код в этом архиве — исходная версия **v0.1**, а документация описывает согласованное направление разработки. Ни рекомендательный алгоритм, ни AI-интеграция пока не реализованы. Публичная версия не опубликована.

## Что уже есть в v0.1

- Добавление и редактирование книг, статусы «В планах», «Читаю», «Прочитано», «Не интересно».
- Оценка от 1 до 10 (или без оценки), короткая свободная заметка.
- Поиск по названию и автору, фильтр по статусу, счётчики книг.
- Хранение в `localStorage`, экспорт и импорт JSON, три вымышленных примера книг.
- Адаптивный интерфейс, манифест PWA, service worker и готовая папка `dist`.

Необходимо отдельно проверить совместимость импорта со старым `reading_journal_v2.html`, мобильный и офлайн-сценарии и сборку в текущем окружении. Автоматических тестов в v0.1 нет.

## К чему идём

1. Читатель может поставить оценку и оставить впечатление за одну минуту; заметка необязательна.
2. На основе оценок и тем прочитанных книг детерминированный алгоритм формирует **топ непрочитанных книг** с объяснениями.
3. По отдельному согласию AI анализирует **одну выбранную заметку** и предлагает темы; читатель может их подтвердить или исправить.
4. Рекомендации работают **без AI и без сети** на уже сохранённых данных и темах.
5. Публичная демоверсия демонстрирует сценарий с вымышленными данными, не раскрывая личные записи пользователя.

Утверждена **гибридная архитектура**: AI помогает интерпретировать заметки, а подбор и порядок рекомендаций контролирует обычный алгоритм. Подключение конкретного AI-провайдера и публикация требуют отдельных решений.

## Быстрый запуск готовой сборки

Если в архиве есть `dist`, в PowerShell из распакованной папки:

```powershell
py -m http.server 4317 --bind 127.0.0.1 --directory dist
```

Открой <http://127.0.0.1:4317/>. Это **сборка v0.1**; будущие функции в ней отсутствуют.

## Запуск исходников

Нужен Node.js 20.19+ (ветка 20) либо 22.12+.

```powershell
npm.cmd ci
npm.cmd run dev
```

Vite обычно показывает <http://localhost:5173/>. Данные привязаны к конкретному адресу и порту браузера. Для копирования между адресами или устройствами используй «Данные → Скачать копию» и «Импорт JSON».

Проверка типизации и сборки:

```powershell
npm.cmd run check
npm.cmd run build
npm.cmd run preview
```

Команда `npm test` будет добавлена Codex вместе с тестами; **в v0.1 её пока нет**.

## PWA

После production-сборки открой приложение онлайн, затем проверь перезапуск без сети. Для service worker подходит `localhost`; на отдельном телефоне потребуется HTTPS. На iPhone установка обычно находится в Safari: «Поделиться → На экран Домой». PWA-файлы есть в коде, но ручная приёмка ещё не зафиксирована.

## Первый ручной тест v0.1

1. Добавь «Мою тестовую книгу», укажи автора, статус «Читаю» и заметку.
2. Измени статус на «Прочитано», поставь 8/10, сохрани и обнови страницу.
3. Проверь поиск по автору и фильтр «Прочитано».
4. Скачай JSON, импортируй его повторно и убедись, что записи с теми же ID не дублируются.
5. Если доступен JSON из `reading_journal_v2.html`, проверь его на отдельном тестовом наборе и сравни статусы, оценки и впечатления.

**Не импортируй демонстрационные данные поверх единственной копии личной библиотеки без резервной копии.** В текущей v0.1 кнопка «Показать примеры» добавляет книги в ту же полку; независимый деморежим ещё не сделан.
