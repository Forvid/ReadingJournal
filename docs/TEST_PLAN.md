# План проверки ReadingJournal

**Статус:** тест-кейсы и критерии приёмки, **не отчёт о выполненных тестах**. В архиве v0.1 автоматического тестового скрипта нет.

## Общий принцип

После каждой задачи Codex запускает доступные технические проверки и описывает, как Forvid может вручную подтвердить результат. Forvid сравнивает ожидаемое и фактическое поведение. Для тестов используются **вымышленные данные и отдельная резервная копия**.

## A. Библиотека и хранение

| ID | Действие | Ожидаемый результат |
| --- | --- | --- |
| T-01 | Создать книгу с названием, автором, статусом «Читаю» и заметкой | Книга появляется в полке с правильными данными |
| T-02 | Изменить статус на «Прочитано», поставить 8/10, обновить страницу | Статус, оценка и заметка сохранились |
| T-03 | Найти книгу по автору, затем отфильтровать по статусу | Показаны только совпадения, пустой результат объяснён |
| T-04 | Скачать JSON и повторно импортировать его | Нет дубликатов по ID и потерь локальных изменений |
| T-05 | Импортировать повреждённый/неизвестный JSON | Понятная ошибка, существующая библиотека не меняется |
| T-06 | Импортировать проверенную копию старого дневника v2 | Названия, авторы, статусы, оценки и впечатления перенесены; если нет файла-образца — тест не выполнен |
| T-07 | Создать/редактировать запись без заметки или оценки | Можно сохранить; отсутствие данных не подменяется вымышленными |
| T-08 | После реализации удаления удалить тестовую книгу | Удаляется только выбранная запись, есть защита от случайного удаления |

## B. Рекомендательный алгоритм (после RJ-05)

| ID | Действие | Ожидаемый результат |
| --- | --- | --- |
| T-09 | Отметить книгу прочитанной, поставить 9/10, подтвердить две темы | Интерес к этим темам повышается, топ пересчитывается |
| T-10 | Изменить оценку 9/10 на 2/10 | Влияние тем становится отрицательным, порядок пересчитывается |
| T-11 | Повторить подбор без изменения данных | Список и порядок совпадают, нет случайных перестановок |
| T-12 | Отметить рекомендованную книгу как «Прочитано» или «Не интересно» | Книга исчезает из рекомендаций |
| T-13 | Оценить книгу без заметки, но с известными темами каталога | Рекомендации используют известные темы, AI не требуется |
| T-14 | Оставить все книги без оценок или без подходящих тем | Нет ложных персональных объяснений, интерфейс корректно сообщает о недостатке данных |
| T-15 | Отключить интернет после сохранения полки и открытия production-PWA | Каталог и рекомендации доступны без AI при выполненных условиях офлайн-кеша |

## C. AI-анализ заметок (после RJ-03)

| ID | Действие | Ожидаемый результат |
| --- | --- | --- |
| T-16 | Нажать «Определить темы» при пустой заметке | Не отправлять запрос; предложить написать заметку или выбрать темы вручную |
| T-17 | Открыть предпросмотр и отменить | Ни один текст не отправлен модели |
| T-18 | Подтвердить анализ одной заметки | Уходит только показанный текст; отображаются ожидание, затем предложенные темы |
| T-19 | Отклонить или исправить тему AI | В профиль попадают только принятые пользователем темы |
| T-20 | Смоделировать тайм-аут, ошибку сервиса или неверный формат ответа | Понятная ошибка, записи сохранены, AI не перезапускается автоматически |
| T-21 | Изменить заметку после AI-разбора | Старые темы помечаются к пересмотру, новый вызов только по согласию |
| T-22 | В публичном демо проверить лимиты запросов и отсутствие ключей в браузере | Нельзя неограниченно расходовать API или увидеть секрет в клиентской сборке |

Тестовые заметки для проверки AI должны включать краткие и длинные формулировки, отрицательную оценку, несколько возможных тем, неоднозначное впечатление и случай без полезных тем. Модель не должна добавлять неупомянутые события сюжета.

## D. Демоверсия и портфолио (после RJ-04)

1. На чистом профиле браузера открыть опубликованную ссылку без регистрации.
2. Увидеть или выбрать тестовую библиотеку **без доступа к личным заметкам** Forvid.
3. Изменить оценку одной книги и увидеть, как изменился топ и объяснения.
4. Проверить узкую мобильную ширину, клавиатуру, закрытие диалога и длинные названия/заметки.
5. Перезагрузить страницу, проверить ожидаемое сохранение; проверить восстановление из JSON.
6. Если AI отключён в демо, интерфейс честно сообщает об этом; если включён — проверить согласие и защиту бюджета.
7. README содержит корректную ссылку, список реализованного и явное описание вклада Forvid и Codex.

## Команды (после появления необходимых зависимостей)

```powershell
npm.cmd ci
npm.cmd run check
npm.cmd run build
```

В RJ-05A командой `npm.cmd test` запускаются доменные тесты через встроенный тестовый раннер Node.js и tsx. Они проверяют каталог, расчёт, основания и работу с записями v0.1 в памяти. Ручной пример есть в README. Проверка экрана и офлайн-перезапуска с рекомендациями (T-15) относится к интеграции RJ-05B.
